# Калькулятор стоимости сайта

Веб-инструмент для digital-агентства, который позволяет рассчитать примерную стоимость и сроки разработки сайта на основе выбранных параметров.

## Возможности

- Выбор типа сайта (лендинг, корпоративный сайт, интернет-магазин)
- Настройка количества страниц
- Выбор дополнительных функций (форма заявки, каталог, онлайн-оплата, интеграция с CRM, мультиязычность)
- Выбор срочности проекта
- Расчёт примерной стоимости и сроков выполнения
- Детальное пояснение, из чего складывается оценка

## Технологии

- **Backend:** Python 3, Flask
- **Frontend:** HTML5, CSS3
- **Конфигурация:** python-dotenv для работы с .env файлом

## Установка и запуск

### 1. Клонирование проекта

```bash
git clone https://github.com/AlenaSygrysheva/test_Space_Free.git
```

### 2. Создание виртуального окружения(базово)
Создайте новое виртуальное окружение(или используйте существующее) командой:
```
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
Установите зависимости командой:
```
pip install -r requirements.txt
```

### 4. Настройка конфигурации
Создай файл .env в корне проекта и копируйте туда значения из .exapmle.env. Все значения можно менять или оставить по умолчанию.

### 5. Запуск приложения
Запустите приложение командой:
```
python app.py
```

Приложение запустится по адресу: http://localhost:5000
